书签小屋 · Bookmark House

隐私政策

生效日期：2026 年 11 月 9 日 · 适用于书签小屋 Chrome 扩展

书签小屋用于保存、回顾和整理网页收藏与浏览器书签。收藏内容保存在当前设备、当前 Chrome 个人资料的扩展空间中。开发者不接收你的收藏，不提供收藏上传服务器，也不使用广告、第三方统计或远程模型服务。

1. 扩展处理哪些信息

  • 浏览器书签的网址、标题、文件夹结构，以及 Chrome 提供的添加或最近使用时间（如果可用），用于书签库展示、搜索、分类、移动、编辑、恢复和导出。
  • 你主动保存或导入的网页网址、标题、正文摘句、本地生成的摘要、站点名称、作者和发布日期，以及你填写的备注、星标、阅读状态和收藏日期。
  • 你选择保留的本地预览图片。使用工具栏的封面选项时，扩展可以保存当前可见页面的缩略截图；部分页面也可复用已加载的文章图片。截图或文章内容可能包含页面上当时可见的个人信息，请按需选择保存。
  • 侧栏宽度、显示偏好、缓存索引、操作撤销记录、回收站副本和最近一次清理前备份，以及用于避免反复读取失败页面的重试记录。

扩展不读取密码管理器或浏览器的全部历史记录，不专门采集表单输入、登录凭据或支付信息。用户自行保存的页面正文或备注仍可能包含个人信息，这些内容按收藏数据在本地处理。

2. 这些信息如何使用

信息仅用于本扩展的收藏与书签管理功能，包括内容展示、搜索、主题分析、生成正文摘要、目录整理、备份和恢复。摘要与主题识别使用随扩展一起安装的本地规则，不向外部模型发送正文。页面加载计时也只在当前弹窗中显示，不发送给开发者。

3. 哪些情况下会访问网站

通过工具栏主动保存网页时，扩展使用临时的当前标签页权限读取你选择的主页面。为已保存链接补充或更新内容时，扩展会按站点请求可选访问权限。站点获准后，扩展可能在你展示这些收藏时读取该站点已保存页面，或读取你已打开的对应页面，以补充缺失内容。

直接读取公开网页及同站封面的请求发往你选择的网站，不经由开发者服务器；这些请求省略 Cookie、不发送来源网址，也不自动跟随跳转。原网站可能按自身政策收到常规网络信息，如请求的网址和网络地址。读取已打开页面时，可以读取你当时已登录后显示的内容，但不会提取或传送登录凭据。

打开收藏链接会按正常浏览方式访问相应网站，适用该网站自己的隐私规则。

4. 数据保存与共享

收藏、图片、备注与扩展内部回收站保存在本机 IndexedDB；布局偏好保存在本机浏览器存储。开发者不出售、不出租这些数据，不将它们用于广告、跨站跟踪、信用或贷款决策，也不向其他主体提供收藏数据。

你可以主动导出 JSON 或 HTML 备份，并自行决定如何保存和分享这些文件。书签库直接管理 Chrome 的真实书签；如果你开启了 Chrome 书签同步，相关书签更改可能由 Chrome 同步到其他设备，适用 Google 的相关政策。扩展内部网页卡片和回收站不会通过本扩展同步到其他设备。

5. 保留、修改与删除

你可以在小屋中查看、修改、导出和删除收藏。删除项先进入内部回收站，回收站不会按时间自动清空。手动永久清空前，扩展会保存最近一次清理前备份；该备份会在后续清理时替换，或在扩展本地数据被删除时移除。整理操作也可能保留本地恢复记录。

卸载扩展会删除对应扩展空间中的本地收藏和缓存，但不会删除 Chrome 中原有的书签、已导出的文件或 Chrome 同步保留的其他副本。重要收藏请先导出备份。开发者无法远程查看或代为删除你设备中的收藏数据。

6. 权限说明

  • bookmarks：管理浏览器书签和目录，支持整理、备份与恢复。
  • activeTab：在你主动使用保存入口时，临时访问当前选中的网页。
  • scripting：运行扩展内置的正文和元信息读取函数。
  • contextMenus：提供网页和链接的右键收藏入口。
  • 可选网站权限：按站点授权，补充已保存页面的内容；可在 Chrome 扩展设置中撤销。

扩展不下载或执行远程代码。通过 Google / Chrome 接口获得的信息，仅用于本政策披露的收藏与书签管理功能，并遵守 Chrome Web Store 用户数据政策及其有限使用（Limited Use）要求。

7. 本政策网页与更新

本政策网页不包含广告、第三方统计脚本或收集表单。访问公开政策页时，网页托管服务会处理提供网页所需的常规网络信息。政策如有变更，会在本页更新生效日期；涉及功能和权限的变化也会随扩展版本说明披露。

Privacy summary in English

Bookmark House saves and organizes user-selected webpages and Chrome bookmarks. It handles saved URLs and titles, folder structure, available bookmark timestamps, selected article text and metadata, locally generated excerpts, optional preview images, notes, stars, read status, preferences, caches, undo records and recovery backups.

Collection data stays in the extension's local browser storage. The developer does not receive, sell or use it for advertising, cross-site tracking, credit or lending decisions. No analytics service or remote AI model is integrated. Local analysis and summaries use code packaged with the extension.

Saving the current page uses user-initiated activeTab access. Optional per-site permissions allow reading saved pages or a matching already-open page. Authorized visible saved pages may be checked for missing content. Direct public-page requests go to the selected original website, omit cookies and referrers, and reject redirects; the website may receive normal network information. The optional visible-page screenshot and saved article text may contain personal information present on the page. Opening a saved link is normal browsing governed by that website.

Chrome may synchronize changes to native bookmarks if the user enabled Chrome bookmark sync. This extension does not synchronize its own card collection or private trash. Users can edit, export and delete saved items. Trash does not automatically expire. Permanent clearing retains the most recent pre-clear recovery backup until it is replaced or local extension data is removed. Uninstalling removes extension-local data, but not native bookmarks, exported files or other synchronized copies.

The use of information received from Google or Chrome APIs is limited to the disclosed collection-management purpose and complies with the Chrome Web Store User Data Policy, including Limited Use requirements. The policy website contains no advertising, analytics scripts or data-entry forms; its hosting provider processes normal website delivery information.
