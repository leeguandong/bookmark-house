2.4.7 商店发布准备

2.4.6 缩短弹窗出现前的加载
- 弹窗首次加载仅保留独立样式和无模块依赖的小入口；页面完成加载后，再加载收藏核对与保存控制。
- 保存功能模块尚未加载时，「打开我的收藏」仍可使用；不读取数据库或提取网页。
- 去掉后台每次唤醒时的额外书签库预热，安装、浏览器启动和书签变化仍会更新缓存。
- 弹窗右下角显示版本号；点击可查看页面加载和网页识别用时。此计时不包含 Chrome 创建弹窗之前的等待。
- 重新加载原扩展后，弹窗右下角显示 v2.4.6。

2.4.5 工具栏保存更快响应
- 弹窗先显示当前网页并启用保存，收藏核对和较大的功能模块在后台加载；打开小屋按钮独立可用。
- 保存时立即尝试读取当前页面，不再等待网页空闲；正文与封面的可选读取共用约 1.8 秒等待预算。超时仍保存链接和备注，可稍后更新内容。
- 收藏核对、合并内容及备注更新由保存时的一次事务完成，减少多次整库读取和连续写入。未编辑的备注使用最新存储值，手动标题和摘要继续保留。
- 延迟返回的核对结果不覆盖正在输入的备注或已保存提示；重复点击受到限制，保存中明确显示进度文字。
- 重新加载原扩展后工具栏弹窗生效；小屋页刷新后左下角显示 v2.4.5。

2.4.4 刷新后先能浏览
- 缓存首页与管理模块同时加载；已有卡片链接和侧栏伸缩无需等待完整收藏读取，修改类操作在最新数据就绪后启用。
- 书签库与网页收藏独立加载，普通打开不再申请全局写入锁；确有恢复或迁移任务时仍按原规则处理。
- 不再在刷新时给全部收藏排队补充摘要；先显示卡片，再检查当前展示的内容，离开页面时跳过待开始的检查。
- 后台数据核对保留当前目录和搜索；读取某一类收藏失败时，另一类仍可使用。
- 重新加载原扩展并刷新小屋页，左下角显示 v2.4.4。

2.3.1 书签库预缓存
- 提前保存浏览器书签的目录索引、各目录数量和重复网址分组。小屋关闭时，后台也会根据书签的新增、修改、移动、删除和重新排序更新缓存；批量导入结束后统一处理。
- 打开时直接使用有效缓存，随后核对浏览器最新数据；相同内容复用已有索引和列表。缓存超过 5 分钟、格式异常或不可用时重新读取，不影响原始书签。
- 多个页面共用缓存，更新时使用版本标记与浏览器锁，避免旧读取覆盖新数据。书签库的实际修改、备份与恢复仍由最新浏览器数据核对，内部回收站使用当前本地记录。
- 原有网页卡片的首页缓存继续保留。重新加载原扩展并刷新小屋页，左下角显示 v2.3.1。

2.3 首页缓存与再次打开提速
- 在本机缓存首页最近 24 张卡片的文字、日期和数量信息，封面仍按需读取；缓存随收藏保存、更新、删除、恢复一同提交。
- 再次打开时先显示首页缓存，再加载完整管理功能并核对最新收藏。核对前暂停操作；发现变化后显示最新内容，缓存不参与删除、恢复或导出。
- 数据未变化时沿用已经显示的卡片，书签库加载后只更新书签标记，避免重复重建列表。日期格式器与当前页面的绘制结果也会复用。
- 侧栏宽度与折叠状态从首屏开始沿用。缓存缺失、格式不支持或损坏时，自动使用常规读取方式；原收藏与备份保持完整。
- 第一次升级后自动建立缓存，之后打开即可使用。重新加载原扩展并刷新小屋页，版本号为 v2.3.0。

- 删除前继续确认，删除后同步到浏览器的实际目录，内部子目录和书签一并进入小屋回收站，可恢复或撤销。网页收藏中的同网址卡片继续独立保留。

2.2 加载与操作提速
- 网页卡片先显示，Chrome 书签目录随后加载。标星、已读、删除和恢复网页卡片，只刷新网页收藏；切回窗口而数据未变化时保留当前页面。
- 封面和清空前备份独立保存在本机；首页只读取当前显示卡片的封面，滚动翻页时继续加载。工具栏保存入口也不再读取全部封面。
- 内容摘要按批更新，忽略本页发出的重复刷新通知；分析页更新时不再重建隐藏的卡片列表。
- 自动读取失败后，30 分钟内不因重新打开小屋重复尝试；主动点击「更新内容」「生成网页摘要」仍会立即重试。
- 原收藏自动转换一次本地存储布局，日期、备注、标题、摘要、封面和回收站备份继续保留；转换失败时原数据完整保留。JSON 导出仍包含完整封面，可照常导入。
- 更新方式：在 Chrome 扩展管理中重新加载原来的书签小屋，再刷新已打开的小屋页。版本号为 v2.2.0；无需卸载或重新导入，没有新增权限。

1.9 自动内容摘要
- 网页卡片直接显示从原文提取的内容摘要，最多三句；优先从正文选句，简介作为备用。不根据标题或网址编造内容，不调用外部模型，也不需要填写 API 密钥。
- 识别 article/main、微信正文区、常见博客正文区和 JSON-LD articleBody；在许可范围内，优先读取已经打开的对应网页，因此可以提取部分动态页面的已渲染内容。文字提取跳过导航、表单、隐藏区域和重复段落。
- 保存、粘贴或拖入链接时尝试申请该网站访问许可；浏览器已允许后自动提取摘要。拖入事件若不能唤起授权，可点顶部「生成网页摘要」一次，允许访问相应站点后继续。无需逐张填写简介。
- 打开小屋后会自动处理已允许网站中缺少摘要的旧卡片；顶部「生成网页摘要」可一次处理现有网页收藏，不扫描 Chrome 书签库。每次最多并行读取两个网页，失败不会反复请求。
- 卡片移除「内容待补全」「暂未提供简介」和大块补全提示。无法读取时保持紧凑的标题与备注布局，保留真实收藏，不虚构摘要。卡片底部小图标可重新生成摘要。
- 手动摘要和备注保持原样，保存日期不变。摘要参与搜索，随收藏 JSON 一起备份。受登录、跳转、反爬或页面结构限制时，个别网页仍可能无法读取。
- 请在 chrome://extensions 重新加载原来的书签小屋，再刷新小屋页面；不要卸载。此版本沿用 1.8 的权限，没有新增权限种类。


1.8 网页内容卡片
- 卡片展示标题、真实网页简介或正文摘录、来源、作者（网页提供时）、保存时间与独立备注。无封面时使用紧凑布局，不显示空白备注占位。
- 工具栏保存当前页时，通过 activeTab + scripting 读取主页面的公开描述；没有描述则尝试提取文章首段，不读取表单值。弹窗可勾选「用当前可见画面作封面」，会将可见网页画面缩小为本机 JPEG 预览；取消勾选则不新建截图。
- 快捷键与页面右键收藏也提取简介，不自动截图。右键收藏一个链接时不会误用所在页面的内容。
- 已保存或从外部拖入的卡片，点「补全内容」可读取该网页的公开标题、简介和同站封面。首次由 Chrome 询问该网站的访问许可；拒绝时卡片仍保留。只申请当前网站，不要求默认访问所有网站。
- 获准的网站，后续在小屋拖入或粘贴新链接时自动生成摘要；可以在顶部统一生成已有卡片的摘要。不扫描整个书签库。
- 补全请求直接访问原网站、不带登录 Cookie、不跟随跳转；不会向小屋服务器或 Codex 上传收藏。只缓存同站封面，不额外访问第三方图片服务器。依赖登录、跳转、动态脚本或反爬验证的网页可能无法补全；可打开原网页使用工具栏保存，或编辑卡片手动填写简介。
- 自己修改的标题、简介和备注不会被自动简介覆盖；收藏日期保留。改网址会清除旧网页的预览。编辑中可移除封面，搜索也包括简介、来源与作者。
- 预览和简介随网页收藏 JSON 一起导出、导入。单个封面最多约 90 KB；导入文件上限 100 MB。此功能保存链接、简要内容和缩略图，不是离线网页全文备份。
- 更新：在 chrome://extensions 中对原「书签小屋」重新加载，再刷新小屋页面。无需卸载，原卡片和书签继续保留。新增 scripting 权限和可选网站权限需重新加载扩展生效。


1.8.0 明确拖入范围，兼容链接来源的拖放模式
- 当前支持拖入地址栏中的网址、页面内的链接及其他应用明确提供的网页链接；不支持把 Chrome 顶部整个标签页拖成收藏卡片。原生标签页拖动与页面链接拖动不是同一个入口。
- 已移除容易混淆的「拖网页」描述，在拖入区明确显示限制。请拖网址或网页链接，或使用工具栏、右键和快捷键保存当前页。
- 对仅允许 link 操作的外部来源使用 link 模式，对允许 copy 的来源使用 copy 模式；不将 move-only 来源冒充复制收藏，避免要求来源移动或删除原内容。
- 此次代码与合成事件测试验证了链接操作模式兼容；Windows 浏览器现场操作工具仍因无法确认当前网址而中止，未完成真实 Chrome 原生拖动验收。

1.7.2 保留拖拽，接收来自其他应用的链接
- 拖拽继续作为网页收藏的主要入口。只要微信浏览器或其他应用能向外提供网页链接，小屋即可接收；同时发送预览图文件信息时，优先读取其中的链接，不读取文件内容。
- 支持纯网址、标题与网址分行、标题与网址同行、常见分享前缀，以及普通 HTML 链接标题。微信文章的查询参数继续保留，同一网址不重复生成卡片。
- 对方无法拖出链接时，在原应用选择「复制链接」，回到网页收藏空白处按 Ctrl + V；也可点击「粘贴链接或分享内容」后确认保存。输入框内仍保留正常的粘贴行为；粘贴到网页地址框时可识别并拆分标题和网址。
- 拖来的内容如果只有图片、文件或应用内部地址，小屋不会猜测网页地址，会提示复制普通网页链接。各应用是否允许向外拖出链接，由来源应用决定。
- 新增方式使用主动拖拽或粘贴事件提供的内容，没有后台读取系统剪贴板，也没有新增权限。Chrome 工具栏、右键和快捷键继续保留，用于 Chrome 中的网页。

1.7.1 更顺手的收藏入口
- 工具栏：点击小屋图标，再点「保存到小屋」。自动带入当前网页标题和网址，可填写备注；保存后留在原网页。只有点击「打开小屋」才进入管理页面。
- 已收藏的网页会显示原有备注，可直接更新；保存日期与自己修改过的卡片标题继续保留。
- 右键：在普通网页或网页中的链接上右键，选择「收藏到书签小屋」。在链接上使用时只收藏该链接；未知的目标网页标题先用域名，可随后编辑。
- 快捷键：Windows 默认 Alt + Shift + S，Mac 默认 Command + Shift + S，直接保存当前网页。若快捷键冲突，可在 chrome://extensions/shortcuts 中重新设置；工具栏弹窗会显示 Chrome 实际分配的组合键。
- 右键或快捷键保存成功后，图标短暂显示勾号；遇到重复网页时保留原来的日期与备注。拖拽和粘贴网址继续可用。
- 在 Chrome 扩展管理中，对原来的小屋重新加载一次，启用菜单和快捷键。不需要移除或重新安装，原有数据继续保留。

1.7 网页收藏：独立于 Chrome 书签的卡片空间
- 小屋现在默认打开「网页收藏」；左侧「书签管理」默认关闭，内部书签栏目录也默认折叠。点击展开后，原有搜索、分析、整理、拖拽和回收站继续可用。
- 把网页里的链接或地址栏中选中的完整网址拖入网页收藏页面，即可保存卡片。也可点击「保存网页」，填写网址、标题和备注。
- 卡片按保存日期分组，支持最近/最早排序、按月份筛选、搜索标题/网址/备注、星标和已读标记。同一网址重复保存时保留原日期与备注，不生成重复卡片。
- 点击卡片「加入书签」，选择实际 Chrome 目录即可加入；网页卡片继续保留。移除卡片不会删除 Chrome 中已有的书签，删除书签也不会移除卡片。
- 卡片移入「已删除」后可撤销或恢复；清空前自动保留卡片备份。网页收藏的 JSON 导入/导出包含标题、网址、备注、日期和阅读标记，与原有 HTML 书签备份分开。
- Chrome 工具栏的小屋图标现在提供「保存到小屋」和「打开小屋」。在主动点击图标、右键收藏或使用快捷键时，临时取得所需网页的标题和网址；只读取主动收藏的主页面信息，简介缺失时尝试提取文章首段，不上传到外部服务器。
- 本功能保存网页链接和收藏信息，打开卡片时访问原网页。网页收藏、正文笔记和回收站均只保存在当前扩展本机空间，卸载扩展前请导出重要内容。

1.6.1 文件夹范围
- 进入文件夹后，顶部仅统计此目录及其子目录的收藏数、子文件夹数、目录内重复和本层收藏；点击重复或本层收藏可在当前目录筛选，点击目录内收藏恢复全部。
- 文件夹页「备份此文件夹」只导出该目录及内部层级；「整理此文件夹」自动选择当前目录为整理范围与分类位置。轻整理会归类本层书签，保留子目录中已有的归类。
- 目录内查重与整理只比较该范围中的网址，目录外的副本不会使当前目录唯一的收藏被精简。所有书签页面保留全局统计、全局备份与整理入口。

1.6 内部回收站
- 回收站仅在书签小屋里显示，不再创建 Chrome 的真实回收站目录。
- 刷新原有书签小屋页面（Ctrl + R）即可更新。首次打开先保存完整迁移备份，再迁入旧回收站内容，最后移除空的旧目录。
- 如果「书签小屋」下仍有正常使用的分类目录，会保留这些内容；只移除空的自身容器，不按名字删除其他同名目录。
- 删除书签或文件夹时，先持久保存完整内容，再从 Chrome 移除。可单条、整夹还原，保留层级、顺序、正文与笔记。
- 还原会新建 Chrome 书签，Chrome 分配的书签 ID、添加时间会更新。原位置已移除或不可写入时，使用可写入的顶层目录。
- 删除、还原、移动、归类、编辑保存最近 30 次撤销记录。中断时保留恢复记录；有外部变化的项目保留现状。
- 一键清空仅删除内部回收站记录，不删除 Chrome 里正常使用的书签；清空前保存备份，之后可在回收站导出。
- 回收站、正文笔记、撤销记录与自动备份仅存于当前扩展空间，不随 Chrome 同步；卸载扩展或清除扩展数据会丢失，请先导出重要内容。

备份
右上角「备份书签」导出全部现有书签及内部回收站，后者单列为「小屋回收站（仅本地）」。文件格式为 Chrome 可导入的 HTML。
底部「导出操作前备份」导出最近一次整理前快照。回收站「导出清空前备份」导出最近一次清空前完整快照。
HTML 不包含正文笔记；在「正文与笔记」弹窗可另行导出正文、笔记与自定义主题 JSON。
通过 Chrome 导入 HTML 会新增书签，请先检查现有内容，避免重复。

拖拽链接
按住收藏清单的链接文字或网站图标，拖到左侧具体文件夹，高亮后松手移动，Chrome 中的位置同步更新。勾选多条后拖动其中一条，可整组移动。
悬停约半秒展开折叠目录；靠近目录区域上下边缘可滚动。拖到空白处松手或按 Esc 取消。
外部 http / https 链接也可拖入新建收藏，初始名称使用网址；目标目录已有完全相同的网址时跳过。拖拽支持撤销，原有书签移动保留 ID 和笔记。

自动整理
自动生成归类、精简完全重复网址、合并同一父目录下的同名目录、收起空目录的方案。预览、勾选后执行，整份方案可撤销。
轻整理保留现有主题目录，全面整理允许重新归类。可选择范围、新分类位置和最低数量；优先沿用已有主题目录。
标题、网址路径、主动补充的正文和笔记、自定义主题参与本地判断；线索不足时保持原位。
预览后内容发生变化会要求重新生成。新分类目录已有外部新增内容时，撤销会保留目录与恢复记录。

书签分析
主题、关键词与命中依据、网站来源、十二个月收藏时间线、文件夹分布、整理与回顾线索；可按文件夹、时间和关键词筛选，点击图表查看关联书签。
正文与笔记可主动补充，可导出 HTML / JSON 分析报告、正文与主题 JSON。书签分析仍使用已保存内容与本地规则，不自动遍历网页，也不调用外部模型；网页卡片可单独使用上方补全功能。
缺少最后打开记录时显示未知，不会据此推断未读。书签网址变更后，旧正文暂停参与分析，核对保存后继续。

权限与同步
申请 bookmarks（管理 Chrome 书签）、activeTab + scripting（主动收藏时读取当前主页面的标题、简介或首段），以及 contextMenus（显示右键收藏菜单）。工具栏中可选择保存可见画面的本机缩略图，图中可能包含页面上可见的信息。可选网站访问权限按站点请求，用于补全指定网页的公开信息；不会默认访问所有网站，不扫描书签库。补全直接访问原网站，预览存于本机，不向 Codex、小屋服务器或外部模型上传收藏。
Chrome 中的移动、编辑、删除仍遵循原书签同步设置，可能影响其他设备。内部回收站只保留于当前本机扩展中。
Chrome 原生「所有书签」入口由「其他书签」是否有内容决定；个人收藏仍会保留原位置。
