# 安装与使用

## 加载源码版

1. 下载并解压源码，或克隆 `https://github.com/leeguandong/bookmark-house.git`。
2. 打开 Chrome 的 `chrome://extensions`，开启“开发者模式”。
3. 选择“加载已解压的扩展程序”，选中仓库的 `extension/` 子目录。
4. 将书签小屋固定到工具栏。打开普通网页后点击图标，即可保存；弹窗中的“打开我的收藏”进入管理页。

加载源码版只需要 Chrome 109+。Node.js、Python 和 npm 依赖用于开发检查，不是扩展运行的前提。

## 选择语言

首次打开跟随浏览器语言。在管理页右上角或保存弹窗选择“简体中文 / English”，本机会记住选择，右键菜单也随之更新。你的收藏正文、备注、自定义主题和文件夹名称保留原文。

## 保存网页

- **工具栏：** 点击图标，确认标题、可选备注与封面后保存。
- **右键：** 在网页或链接上使用“收藏到书签小屋”。
- **快捷键：** Windows / Linux 默认 `Alt+Shift+S`，macOS 默认 `Command+Shift+S`；可在 `chrome://extensions/shortcuts` 修改。
- **粘贴：** 在管理页粘贴完整网址，或其他应用复制的“标题＋分享链接”。
- **拖拽：** 拖入地址栏网址或网页内链接。Chrome 顶部整个标签页无法直接拖入管理页。

卡片按收藏日期展示。可以搜索、添加星标、编辑备注与摘句，以及标记阅读状态。内容提取受网页结构、登录与站点限制影响；原网页保持打开，或允许对应站点访问后重试，可能补充更多内容。

## 管理书签

展开左侧“书签库”浏览 Chrome 的真实目录。可将卡片拖入具体目录；右键文件夹执行相应操作。移动、编辑和删除会作用于真实 Chrome 书签，并受浏览器自身同步设置影响。

同一网址的网页收藏与原生书签各自独立。删除当前来源的内容，不会连带删除另一份。整理中心先生成方案，检查后再执行。

## 更新与迁移

已加载源码版时，在原目录更新文件，然后到扩展管理页点击“重新加载”，再刷新管理页面。不要先卸载原扩展；卸载会删除该扩展 ID 的本地数据。

如果更换源码目录或改用商店版，请先从旧安装导出网页收藏 JSON，并在新安装中核对导入结果。不同扩展 ID 的本地数据不自动共享；Chrome 原生书签仍由浏览器管理。

如当前安装仍来自旧工作目录，可以继续使用原目录。本仓库结构整理不会自行移动你的安装或浏览器数据。

## 删除、回收与备份

回收站按来源查看和恢复，永久清理前请确认内容。一键清理保留最近一次清理前恢复备份，直到它被后续备份替换或本地扩展数据被移除。

重要收藏应另行导出。导出的文件可能包含私人内容，请保存在自己的受控位置，不要提交到 Git 仓库。

完整数据说明见[隐私政策](https://leeguandong.github.io/bookmark-house-privacy/)。
