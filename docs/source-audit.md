## 检查方式与结果

- 检查了常见私钥文件、凭据文件、已知 API token 格式、密码/访问令牌常量及含凭据的网址，未发现命中。
- 使用 Secretlint 13.1.0 及同版本推荐规则集作独立内容扫描，未发现命中。扫描在本机执行，不向凭据服务发送待检查内容。
- 提交前钩子对 Git 暂存区的实际内容运行两套检查；报告仅记录规则名、路径和行号，不打印命中值。
- 原始代码目录没有 Git 历史；首次入库从本次审核的快照开始，不携带工作区旧备份。
- 政策与安装说明中保留的开发者联系邮箱属于既有公开联系渠道，不是访问凭据。测试中的网站、笔记编号和分享参数为合成样例。
- 扩展运行文件与已提交商店的 2.4.7 包核对，未修改运行逻辑。开发依赖、测试、文档和检查工具不收入商店包。

## 限制与维护

本记录只说明本次选定文件的检查结果，不保证未知格式、编码后的秘密或所有个人数据都能自动识别。提交新的数据文件、接入外部服务或公开仓库前，需要重新审查全部内容及待推送历史。

开发者于 2026-11-11 决定公开源码。本次开源保留已公开的政策联系邮箱；不提交个人收藏、账号令牌、浏览器资料或真实网页快照。源码采用 MIT 许可证，开发依赖使用各自许可证。

初次公开提交曾使用 `leeguandong/bookmark-house-privacy`。项目随后整理为独立的 `leeguandong/bookmark-house` 源码仓库，原仓库继续托管既有隐私政策地址。源码放入 `extension/`，测试与开发工具分别归档；原商店包的 55 个运行文件未改变，Git 文本统一使用 LF。打包时另附 MIT 许可证。结构整理后重新验证资源引用、测试、打包与完整暂存内容。
